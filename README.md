## 改ざん不可能性の仕組み

```
毎朝 07:00（東京時間）
  ① AIが銘柄・エントリー価格・TP/SL・判断理由を生成
  ② 予測内容をJSON化 → SHA256ハッシュを計算
  ③ ハッシュのみを GitHub にコミット・プッシュ
     └─ このコミットのタイムスタンプ = 「予測確定日時」の証拠

大引け後 16:00 以降
  ④ 原本 JSON を GitHub に公開
  ⑤ 誰でも自分でハッシュを再計算して検証可能
```

### なぜ改ざんできないのか

- GitHubのコミット日時は**サーバー側**で記録される
- ローカルの時計を変えても、GitHub上のタイムスタンプは変わらない
- 朝7時のコミットに含まれるのは**ハッシュのみ**（予測の中身は非公開）
- 大引け後に公開されたJSONのハッシュが一致すれば、**予測は変更されていない**

### 自分で検証する方法

```python
import hashlib, json

# 公開された原本JSONをダウンロード後:
with open("YYYY-MM-DD_full.json", encoding="utf-8") as f:
    payload = json.load(f)

canonical = json.dumps(payload, ensure_ascii=False,
                        sort_keys=True, separators=(",", ":"))
digest = hashlib.sha256(canonical.encode("utf-8")).hexdigest()
print(digest)
# → YYYY-MM-DD_hash.txt の先頭行と一致すれば改ざんなし
```

詳細は [verify.html](./verify.html) を参照してください。
